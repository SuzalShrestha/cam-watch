# Code of Conduct

This project uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be patient with new contributors, and give constructive feedback.
Harassment and personal attacks are not accepted.

To report a problem, contact the maintainer privately through the contact on the
[maintainer's GitHub profile](https://github.com/SuzalShrestha). Reports are kept confidential.
